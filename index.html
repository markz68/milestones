Sync and recovery details

Sync combines newer event edits and saved deletions. It checks after edits, when you return or reconnect, and about once a minute while visible. Initial merges and conflicting edits may need review. Independently created event IDs remain separate.

Back up creates a separate, verified recovery copy of this device. Restore uses the latest manual Drive backup, or existing sync history if no manual backup exists. Restore previews counts and replaces the local event list only after confirmation. Restored changes can then sync to other devices. Export JSON first if needed.

Disconnect keeps your events and cloud copies. Milestones files remain separate from PTO Tracker and Infinity Bottle. Keep dated JSON exports outside the browser too.
