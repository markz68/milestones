Backup & restore

A JSON backup includes every event, its date precision, and deletion history. Keep copies somewhere outside this browser.

Import merges events and saved deletions. If an ID already exists, the newer change wins. Export a backup first if you want to preserve both versions.

The previous local state is a single undo point for the last save, deletion, or import. It is not a separate backup.
